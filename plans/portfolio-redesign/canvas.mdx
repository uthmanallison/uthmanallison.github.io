<Annotation id="desktop-note" title="One memorable idea: a systems casebook" targetId="desktop-home" placement="bottom">

The layout reads like an engineer's field notebook: restrained grid lines, full-width project records, and architecture-led evidence rather than identical SaaS cards.

</Annotation>

<Annotation id="dark-note" title="Dark-only launch" targetId="desktop-home" placement="right">

The production site uses a fixed midnight-blue and warm-brass palette with `color-scheme: dark`. There is no theme toggle in the first release.

</Annotation>

<Annotation id="mobile-note" title="Responsive behavior" targetId="mobile-home" placement="bottom">

Navigation reduces to two priority links, the hero becomes one column, and project records stack without hiding content or requiring a menu script.

</Annotation>
