Privacy & analytics

This site works without analytics. Google Analytics loads only after you choose to accept it.

What is measured

If you accept analytics, this site sends ordinary page views and four named interaction events:

  • project_open when a case study is opened.
  • source_open if a public source-repository link is available and opened.
  • resume_download when the résumé link is selected.
  • contact_click when an email, LinkedIn, or GitHub contact link is selected.

Event labels identify the page action, not you. The site does not intentionally send email addresses, résumé content, financial data, project data, or URL query strings to analytics.

Consent and storage

Your choice is stored in your browser under portfolio-analytics-consent. Declining means the Google Analytics script is not requested. If browser storage is unavailable, your choice applies only to the current page.

Processor

Google processes accepted analytics data for measurement ID G-VWG0C7WTQ4. Google’s handling of that data is described in the Google Privacy Policy.
